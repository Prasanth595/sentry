import {ApplicationSummary} from './applicationSummary';
import {ConsentForm} from './consentForm';
import {OAuthLayout} from './oauthLayout';
import {OAuthFlowTransition} from './oauthFlowTransition';
import * as Storybook from 'sentry/stories';

The application summary stays visible through sign-in and consent. The flow hook owns preparation, account switching, decisions, and navigation. Consent controls select one organization for organization-scoped applications.

The parent remounts consent controls when the account or prepared transaction changes. The last active eligible organization is preselected, falling back to the first available organization. Consent controls are disabled during account switching and decision submission.

Permission rows share grid columns with a fixed header above the scrollable list. The backend provides resource-specific access descriptions for indicator tooltips and describes special capabilities in the Other column. An X marks unrequested access; cells are empty when an access level does not apply to the resource.

Account switching retains the consent screen with its controls disabled through logout and authentication configuration loading. Once sign-in is ready, the account and consent section transitions together using the invitation flow motion. The application card stays visible throughout.
